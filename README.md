Phantombuster provides real-time sales prospecting automation, allowing users to run web scraping automations 24/7 across 15+ platforms. Their tools generate leads, extract live data, and enrich lists with intent signals, serving over 2.5M satisfied users since 2016. The platform offers features like warm leads, engagement signals, and AI-driven outreach, with a free trial and various pricing plans.

**Areas:** Company · Automation · Sales · LeadGeneration · WebScraping · DataEnrichment

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Phantombuster: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
